# EarlyApply

**Website: https://iamdheeraj0211.github.io/earlyapply/**

EarlyApply is a free Chrome and Edge extension for LinkedIn Jobs. It shows you jobs posted in the last 15 minutes to 12 hours, newest first, hides promoted, reposted and staffing-agency jobs, and sends a desktop alert (Job Radar) the minute a new job matching your search is posted. You still apply yourself; nothing is automated.

- [Add to Chrome](https://chromewebstore.google.com/detail/mdnefacoafkpdmbnjdaijlgahjnebgbo)
- [Add to Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/hnjfgommfnihplmlicjdfkheokdmnnep)
- Guide: [How to see LinkedIn jobs posted in the last hour](https://iamdheeraj0211.github.io/earlyapply/linkedin-jobs-posted-last-hour.html)
- [Privacy policy](https://iamdheeraj0211.github.io/earlyapply/privacy.html)
